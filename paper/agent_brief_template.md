# Paper Agent Brief Template

Use this as a starting point when sending an agent to work on paper text.

## Goal

State the writing task in one sentence.

Example:
Revise the discussion in `paper/positive_skew_report_section.tex` to be tighter and more submission-ready.

## File Ownership

- Edit only: `paper/<target-file>.tex`
- Do not edit: `tex_CAIRO/main.tex`, bibliography keys, or unrelated paper files

## Constraints

- Preserve notation, theorem labels, citation keys, and equation references unless explicitly asked to change them.
- Keep the voice formal and compact.
- Avoid inventing results or changing reported numbers.
- Flag unclear claims instead of papering over them.

## Deliverable

- Return a cleaned draft in the owned file.
- Briefly summarize what changed and any claims that still need verification before merging into `tex_CAIRO/main.tex`.
